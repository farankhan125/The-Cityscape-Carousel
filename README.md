# 🌆 The Cityscape Carousel

The Cityscape Carousel is a simple, clean, and interactive web component built using **HTML, CSS, and JavaScript**. It showcases a collection of **11 capital city cards**, each featuring the **city's name** and a **short description**. Users can slide through the cards using left and right navigation buttons.

---

## ✨ Features

- 📍 11 Capital City Cards
- 📖 City name + short description on each card
- ⬅️➡️ Smooth card sliding with left/right buttons
- 💻 Responsive and lightweight design
- 🎨 Pure HTML, CSS, and Vanilla JS—no libraries

## 🚀 Getting Started

You can run this project locally in just a few steps:

1. **Clone the repository**
```bash
git clone https://github.com/farankhan125/the-cityscape-carousel.git
```
2. **Navigate to the project folder**
```bash
cd The-Cityscape-Carousel
```
3. **Open the folder in your IDE**
```bash
code -a .
```
4. **Open index.html in your browser**
```bash
start index.html
```

That's it! 🎉 No build tools or dependencies required.
